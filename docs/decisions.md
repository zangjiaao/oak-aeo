# 已拍板，骨架按这个做

上传的 PRD v1.0 正文仍是旧口径。实现以这里为准。

- 单品牌 okdata。界面中文。先不登录。
- 引导态全屏，无导航。工作台六页：Agent、机会看板、诊断、内容、品牌设置、系统设置。同一条会话贯穿两态。
- 事实要能对回 `raw_source` 快照。A 级可进内容，C 级口述不能升格，B 级默认不进对外草稿。不按页面预分配条数。
- 采样是人工网页采集。每个模型每天最多 5 次，系统要拦住第 6 次。验证轮是 5 问 × 4 模型 × 1 次。不把重复提问当成独立样本。
- 指标用 Wilson 95% 区间。显著性用问句级 Fisher 检验。样本不足不写「显著」。MVP 不校准、不自动退役。Top3 只在有序列时编码。指标只读已冻结字段。
- 内容审核通过后人工发布。系统只导出 Markdown，URL 以后回填。
- Agent 用 `@earendil-works/pi-agent-core` 和 `pi-ai`，不嵌入 `pi-coding-agent`。模型名和密钥走环境变量。
- 库用 Drizzle + D1，快照放 R2。这一刀还没接。
